## Governing AI agents in delivery

- **[enterprise-agentic-sdlc](https://github.com/dmgrok/enterprise-agentic-sdlc)**: a kit that keeps a coding agent on mission, within budget and producing acceptable work, with an independent controller that can deny a model call, withhold an output or pause a run. [Demo](https://dmgrok.github.io/enterprise-agentic-sdlc/).
- **[claude-cognitive-surrender](https://github.com/dmgrok/claude-cognitive-surrender)**: an experimental CLI for studying approval habits when people review AI agent work.

## Platform tooling for AI coding agents

- **[agent-plugins](https://github.com/dmgrok/agent-plugins)**: a searchable catalog of plugins and skills for AI coding agents, with automated provider intake and security checks. [Browse the catalog](https://dmgrok.github.io/agent-plugins/).
- **[claude-code-lgtm](https://github.com/dmgrok/claude-code-lgtm)**: the `cc-tricks` CLI for Claude Code configuration diagnostics, cost-control presets and token-usage benchmarks.
- **[mcp_mother_skills](https://github.com/dmgrok/mcp_mother_skills)**: an MCP server that detects a project's stack and installs matching agent skills.
