# Hi, I'm David 👋

Principal engineer working on AI across the software development lifecycle and developer experience. I build small, practical open-source tools that help engineers adopt AI coding agents with less friction, and I use them to experiment with agentic software delivery.

## Find and install agent skills

- **[agent-plugins](https://github.com/dmgrok/agent-plugins)**: a searchable catalog of plugins and skills for AI coding agents, with automated provider updates and install tooling. [Browse the catalog](https://dmgrok.github.io/agent-plugins/).
- **[mcp_mother_skills](https://github.com/dmgrok/mcp_mother_skills)**: an MCP server that detects a project's stack and discovers and installs matching skills for Claude Code, GitHub Copilot and Codex.

## Tune Claude Code

- **[claude-code-lgtm](https://github.com/dmgrok/claude-code-lgtm)**: the `cc-tricks` CLI for Claude Code configuration diagnostics, cost-control presets and token-usage benchmarks.

## Experiment with agentic delivery

- **[unconf](https://github.com/dmgrok/unconf)**: an event-management app used as a living lab for agentic software delivery, combining AI-assisted workflows, automated checks and human review.
